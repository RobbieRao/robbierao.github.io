Artisense

A generative-AI art-education prototype exploring reference generation, conversational feedback, and guided practice across mobile and larger-screen interfaces.

Sketch input and reference generation

We gave the learner's drawing and the generated reference separate areas in the Magic sketch prototype. The canvas had brush sizes, a palette, a clear action, and theme presets for animals, plants, landscapes, and architecture. The sketch remained below the reference, ready for further editing.

The proposed ControlNet interaction used the sketch as input for a reference image. Keeping both areas on the same screen let the learner compare the result with the drawing and return to the same controls. A generated treatment stayed visible as one possible reference, while the learner's own marks remained intact.

The brush controls sit beside the canvas as circles of different sizes; the palette uses a color field with a slider beneath it. These are direct editing controls, separate from the theme presets. I check the relationship among three things here: the marks the learner has drawn, the reference produced from those marks, and the next edit. If the sketch changes, the older reference still needs to be read as a result of the earlier input. Keeping the original drawing visible gives the learner something concrete to compare, including the lines and proportions the generated image changed.

Phone and tablet layouts

We separated discovery, drawing, and exercise discussion into individual phone screens. On the tablet, we placed discovery content beside the conversation; another layout paired the learning overview with it. The extra width let the material under discussion stay visible beside the messages. On the phone, the current activity took most of the screen. I prefer this allocation to enlarging every phone component equally: a response about an image is easier to follow when that image stays in view.

Exercise prompts and reference requests

We kept the still-life prompt, the learner's request for a demonstration, and the returned reference images in one conversation. A follow-up could then refer to the same exercise without rebuilding the context. Upload drawing, change prompt, and request changes sat near the conversation, where the learner could move from reading feedback to submitting another version.

Discovery and practice entry points

Discover brought together artist content, daily inspiration, learning reports, community, and help. We also included text, voice, and image input in the assistant proposal: finding a subject, asking about a reference, and submitting a drawing call for different inputs. The drawing task remained the point of return after those exchanges.

I want the reference and the current drawing to remain distinguishable. A learner needs to see which marks are their own before deciding what to change. The separate image areas make that comparison possible.
