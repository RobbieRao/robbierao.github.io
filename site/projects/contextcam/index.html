ContextCam

Bridging Context Awareness with Creative Human–AI Image Co-Creation

A mobile co-creation system turns the situation around a person into ideas for images. Five agents coordinate context selection, topic suggestions, conversation, editing tools and personal preferences.

Xianzhe Fan, Zihan Wu, Chun Yu, Fenggui Rao, Weinan Shi*, and Teng Tu.

CHI 2024 · Full paper

Paper↗Code↗Notebook↗

Start with a situation, not a finished prompt

People may have a place, a feeling or a moment to express before they have a detailed image prompt. ContextCam uses location, weather, music, screen content and facial expression to suggest possible directions, then lets the user choose and revise them through conversation.

Frame an idea, then focus it

  1. Select relevant context

    The Context Selector represents five input modalities as a binary relevance vector. The Topic Agent uses the selected context for two suggestions and a slightly perturbed selection for a third. Interface icons distinguish sources that contribute, sources deemed irrelevant and sources the user has disabled.

  2. Separate conversation from tool execution

    The Artist Agent develops the concept; the Tool Manager prepares generation or editing calls. GPT-4 supports interpretation and ideation, VisualGLM-6B describes images, and Stable Diffusion v1.5 with ControlNet provides visual generation and editing. Paint, Edit and Advice expose different intentions in the floating Android window.

  3. Carry preferences into the next session

    A Personalization Agent condenses completed interactions into preferences for subjects, styles and themes. This memory supports later topic selection and conversation while remaining separate from the current image-editing state.

A formative study with 23 participants informed the design. The real-world evaluation followed a tutorial with three days of use, questionnaires and interviews. Participants often adopted contextual recommendations, with a reported average input of 1.1 words per interaction. Logs and interviews show how context shaped subjects, revisions and inspiration; the study also identifies the need for broader context recognition and more visual creation tools.

Code & materials

ArtAgent-android contains the Android client and Gradle project. The README documents its service endpoints; backend_config.json points the client to a separately hosted inference service.
