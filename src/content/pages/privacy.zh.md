# 了解访问情况

本网站统计访问情况，以了解哪些研究、简历和设计页面对访客有帮助。详细记录不公开，仅可通过网站所有者的 Cloudflare 账户访问。

## 记录哪些信息

私有访问统计会记录页面路径、时间、来源网站、公网 IP 地址、近似国家和城市、网络服务商、浏览器与系统信息、设备类型，以及浏览器语言。不记录 URL 查询参数和片段标识。存储在当前浏览器中的随机标识用于估算独立浏览器数量和回访；两次被记录的页面访问间隔超过 30 分钟时，会开始新的会话。

这些统计估算的是浏览器和会话数量，而非识别具体个人。基于 IP 的位置可能不准确，多人也可能共用一个 IP 地址。

## 你的选择

你可以在下方关闭当前浏览器的私有访问统计。Global Privacy Control 和 Do Not Track 信号也会关闭统计。如果浏览器存储不可用，访问可能在没有持久标识的情况下被记录，因此无法可靠地去重。

## 存储与访问

记录存储在私有 Cloudflare D1 数据库中。原始日志最多保留 365 天，并可能导出供网站所有者分析访问情况。本网站不会通过公开接口暴露 IP 地址或个人浏览记录。访问统计不用于广告或会话回放。

公开的 Homepage views 徽章使用独立的 [Hits 服务](https://github.com/silentsoft/hits)。加载该图片会联系 Hits；上方的私有访问统计偏好设置不会控制这一独立的页面访问计数器。GitHub Pages 和 Cloudflare 也会处理请求，以提供网站和统计服务。
