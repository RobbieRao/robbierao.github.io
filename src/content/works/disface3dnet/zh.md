## 解释从输入开始

把脸颊高亮出来，还不能回答我想问的问题。形状、皮肤和光照都出现在这里，Grad-CAM 很难说明到底是哪一种因素影响了评分。我因此先设计各分支的输入：限定它能够读取的成分，再让它给出参与总分的数值。

监督信号是这里的难点。SCUT-FBP5500 提供 5,500 张照片及 1 至 5 分的整体评分，没有七种成分各自的人工评分。我让各分支共同学习整体目标，再用弱语义标签引导分量含义。五项静态评分位于 \[0,1\]，表情和姿态则提供有正负的调整。因此，成分名称首先是我对模型的约束，不能直接当成人类对该成分的独立评价。

比较方法时，我保留了官方固定五折。每折 4,400 张训练图像和 1,100 张测试图像，训练部分再分为 3,960 张内部训练图像与 440 张验证图像。验证集 PCC 用来选检查点，标准化统计量和融合系数只在内部训练集上拟合，测试前固定。匹配对照共用划分与配对随机种子，避免换模型时连比较条件也一起换掉。

#### 七条分支的输入约定

| 分支 | 表征 | 设计决定 |
| --- | --- | --- |
| 身份形状 | 9 个 UV 通道 + 7 个描述量 | 法线、坐标、曲率，加对称性与尺度；不输入皮肤纹理。 |
| 皮肤 | 12 个 UV 通道 | RGB 反照率与细、中、粗三尺度纹理细节；不输入形状坐标。 |
| 光照 | 3 个 UV 通道 | 在中性网格法线上计算 27 个球谐系数。 |
| 头发 | 掩膜 RGB 图像 | 非头发像素置零，再补成正方形并缩放。 |
| 背景 | 15 维向量 | 颜色、纹理、面积与皮肤对比统计。 |
| 表情 | 7 个 UV 通道 | 位移法线、压缩位移与对数幅值。 |
| 姿态 | 俯仰 / 偏航 / 翻滚 | 原图的视角信息独立于中性几何保留。 |

## 为什么不给皮肤分支形状坐标

我组合 FFHQ-UV、Deep3DFaceRecon 和 HiFi3D++ 获取中性几何、反照率与光照，使用 3DDFA-V3 获取表情和姿态，再用 BiSeNet 分开头发与背景。图像和 UV 输入在吸引力训练前统一缓存为 384 × 384。各折与对照复用同一份缓存，预处理就不会成为额外变化的实验条件。

形状输入采用九个 UV 通道，容纳位置、法线和三种曲率量，另附三个对称性描述量与四个尺度描述量。皮肤输入则是十二个通道：RGB 反照率，加上细、中、粗三种尺度的 RGB 细节，不给它形状坐标。光照将 27 个球谐系数作用于中性网格法线，重建为三个 UV 通道。这样的分配，在计算损失之前就先做了一部分信息分离。

表情需要同一个人的参照。我固定身份系数，用有表情的 BFM 网格减去中性网格，再把位移转到 HiFi3D++ 和 UV 空间。三路位移法线、三路压缩位移与一路对数幅值共同保留变形。压缩采用 3 tanh(z(ΔU)/3)，无效像素置零，标准化使用固定缓存中 500 个样本的统计量，各折共用。

剩余输入不必都做成大图。姿态是弧度表示的 pitch、yaw、roll；背景用颜色、梯度、面积和皮肤对比等 15 维统计量描述；头发保留分割出的 RGB 像素，其余位置置零。UV 图和头发用 EfficientNet-B0，姿态和背景用 MLP。各分支通过独立的 FiLM 缩放与偏移，接收共享的八维基准组别嵌入。这些组别标签由外部提供，推理时仍需要。

## 总分拟合得好，也可能有分支没在工作

七条分支在 PyTorch 中联合训练，优化器为 AdamW，batch size 为 12：先用 3 × 10⁻⁴ 训练 70 个 epoch，再用 3 × 10⁻⁵ 精修 30 个 epoch。EfficientNet-B0 从 ImageNet 权重开始，部分特征块冻结，精修阶段关闭增强。推理时平均原图和水平翻转的预测，同时处理几何、位移及 yaw 的相应变化。

只监督整体评分，会容许一种并不好用的解：某些分支几乎变成常数，其余分支承担大部分拟合。我因此同时检查成分评分的变化尺度和 PCC，用平衡项约束五个静态评分的对数标准差差异。去掉它后，尺度变异系数从 0.082 升到 0.377，PCC 却只小幅变化。这个对照说明，对这套模型只看整体指标不够。

弱语义提供另一组约束。GPT-5.5 为每张图联合生成七种标签：静态目标在 \[0,1\]，表情在 \[−0.10,0.10\]，姿态在 \[−0.05,0.05\]。有效标签绝对误差按成分平均，以 λsem = 0.2 加权。联合目标还包括整体误差、FPEM 蒸馏、21-bin 评分分布、标量与分布一致性及成对排序。一致性项对分布期望停止梯度；排序选择评分差异足够大的样本对。这些约束各管一部分行为，弱标签仍不是人工成分真值。

选定检查点后，我先冻结网络，再拟合融合。静态与动态总量按内部训练集统计量标准化，凸优化拟合两个非负权重和一个自由截距，目标包括基准评分误差，以及权重为 0.3 的 FPEM 目标误差。教师在同一外层折内微调，由内部验证集选择。这一步只更新融合系数；教师、弱标签和分布头用于训练，FiLM 条件化则在部署时保留。

核算贡献时，我保留裁剪前的结果。展开融合表达式得到七项贡献与有效截距，相加精确还原归一化预测；贡献乘以四后得到评分点，最终分数为 clip(1 + 4y, 1, 5)。到了量表端点，裁剪会改变报告总分，却不会改变底层贡献。把这两步混在一起，原本正确的分解反而会看起来对不上。

#### 评分核算：由公式 7–11 简化整理

```
Z_static  = (S_static  - mean_static)  / std_static
Z_dynamic = (S_dynamic - mean_dynamic) / std_dynamic
y_normalized = b0 + W_static * Z_static + W_dynamic * Z_dynamic
             = b_effective + sum(component_contributions)
y_rating = clip(1 + 4 * y_normalized, 1, 5)

# Means, standard deviations and fusion coefficients: inner-training only.
# Each contribution × 4 is in rating points before clipping.
```

## 匹配对照让我看清了什么

五折结果为 PCC 0.8904 ± 0.0063，表 I 中 MAE 为 0.258、RMSE 为 0.337。FPEM 的整体预测更准确。为了知道成分设计付出了多少代价，我只把七个读出和加法融合换成标量头，输入、编码器、条件化和日程都保持一致。对照只少 224 个参数；加法模型平均 MAE 高出 0.0108 个评分点，95% CI 为 0.0078 至 0.0138。

成分诊断改变了我读训练结果的方式。去掉语义引导后，表情与弱标签的相关性从 0.116 变为 −0.188，姿态从 0.212 变为 −0.022。计算量匹配的分阶段训练里，表情评分标准差从 0.0190 降至 0.0023，动态融合系数从 0.0242 降至 0.0034。分支在架构图上还在，实际提供的变化已经很少。这些结果支持保留联合训练。

λsem 依据验证结果选择，不使用测试折。五个验证种子里，从 0 提到 0.2 后，七种成分与弱标签的对应都改善；继续加大权重，部分成分仍有收益，但整体 PCC 下降，光照也没有持续受益。0.2 是综合这些变化作出的选择。

人类比较检验的是另一个问题。20 位成年人各完成 103 次试次，包括练习、成分比较、重复、独立整体比较和注意力检查，也可以回答“不确定”。形状、皮肤和头发的 held-out 成分方向，与 960 次明确回答中的 676 次一致，即 70.4%，按参与者聚类的 95% CI 为 67.1% 至 73.7%。把“不确定”也计入未一致，则是 676/1,200，即 56.3%。我把两个分母都保留下来，因为它们对应的结论不同。

表情的结果弱一些：294 次明确比较中有 123 次一致，约 41.8%。参与者只看当前照片，却要判断哪张脸的表情相对自身中性状态增加吸引力更多，需要自己想象参照，人与人的一致性也较低。看到这个结果后，我更在意参照缺失带来的影响：模型有重建的中性面孔，观察者却各自在脑中补一张。两边的分歧不能全部归因于模型。照明、姿态和背景没有纳入正式人类比较。

做完这些比较，我对“解释”这个词用得更具体了。七项贡献核算了模型的预测，其中部分方向也与指定任务下的人类判断一致。但这两件事都没有测量：单独改变某个面部成分，会让人的印象改变多少。把它们分开以后，分解的价值和这次实验的边界反而都更清楚了。
