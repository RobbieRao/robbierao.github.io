## Sources and editing decisions

Source materials came from `D:/作品集` and `D:/智能所优秀毕业生材料/饶冯桂`, accessed read-only through the owner's RobbiePC-wsl host. The WSL `/mnt/d/` directory corresponds to Windows `D:/`.

`design-projects.json` records the source-to-web image mapping, source hashes, approved years, captions, and page copy. The private review IDs remain only in this content record; they are not displayed on the website. Source files are not modified. WebP derivatives are resized for the web and retain the source composition; EXIF orientation is normalized.

- LightSpoken uses the completed installation, model-making board, and lighting-control board. The mismatched BOSA/OTDR text on the older technical-proposal board is excluded.
- Artisense uses the core interfaces and project identity. Unverified market statistics and efficiency multipliers are excluded. Recognition is described at the verified university/division level. The project is marked as a team project; the record does not infer leadership or specific individual responsibilities. It is not automatically merged with the earlier Virtual Art Education Tutor entry, whose relationship has not been confirmed.
- Liangzhu is described as a generative-design exploration and exhibition concept; the rendered table is not described as a completed exhibition.
- The shopping-cart page presents the design process and physical prototype without claiming measured health benefits.
- 水陌·渔影 uses the approved shortlist name and installation photographs; it does not claim an unverified app-control implementation.
- 家源 and THE LOST HOMELAND are treated as the same team film based on matching poster, text, and footage. The page uses finished images and production documentation without inferring individual film credits.
- Swim the World presents an interaction-design concept and its proposed mobile journey without claiming verified public deployment.
- Digital Human Interaction uses two frames from the source demonstration. As explicitly requested, both the cover and detail-page frames are displayed 90 degrees counterclockwise using CSS. The original frame files are preserved, and the page does not infer the interaction input or an unverified implementation role.

The original six text-based design entries and their existing anchors are retained under “More projects.”
